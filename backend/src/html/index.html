API Endpoints

GET http://localhost:8080/components/

Description: Get all components from the database

GET http://localhost:8080/components/:id

Description: Get a specific component by its ID

POST http://localhost:8080/components/add

Description: Add a new component to the database

Note: The ID is automatically generated using a timestamp to ensure uniqueness during testing.

POST http://localhost:8080/components/add/many

Description: Add multiple components to the database in a single transaction

Note: This endpoint accepts an array of components and uses database transactions for efficiency.

GET http://localhost:8080/vendors/

Description: Get all vendors from the database

GET http://localhost:8080/vendors/:id

Description: Get a specific vendor by its ID

POST http://localhost:8080/vendors/add

Description: Add a new vendor to the database

GET http://localhost:8080/types/

Description: Get all types from the database

GET http://localhost:8080/types/:id

Description: Get a specific type by its ID

POST http://localhost:8080/types/add

Description: Add a new type to the database

Data Structures

Component Data Structure

The Components endpoint returns objects with the following structure: 

{
  "id": 1,
  "type_id": 1,
  "value": "component_value",
  "quantity": 100,
  "footprint": "component_footprint",
  "vendor_id": 1,
  "description": "Component description",
  "vendor_part_number": "VPN123",
  "price": 999
}
}

Vendor Data Structure

The Vendors endpoint returns objects with the following structure: 

{
  "id": 1,
  "name": "vendor_name",
  "description": "Vendor description",
  "url": "https://vendor.com"
}

Type Data Structure

The Types endpoint returns objects with the following structure: 

{
  "id": 1,
  "name": "type_name",
  "description": "Type description",
  "unit": "Ω"
}
}
